# 日常 · 个人生活记录

个人减脂监督与生活记账应用。

现有云端版本：https://quiet-life.spectre4976.chatgpt.site

## 完整源码

下载并解压 `quiet-life-source.zip`，项目位于 `quiet-life/` 文件夹。源码包含前端、云端 API、数据库迁移、测试与部署文档；不包含个人记录、照片、口令、API 密钥或托管平台凭据。

- 体重记录、7日均重、围度趋势及每周总结
- 饮食照片日记、运动、作息、日历及搜索
- 生活费预算、收入支出和数据备份
- 昵称与同步口令连接云端，同步记录和照片
- 未接通的 AI 接口及按钮已移除

## 部署说明

这是完整前后端项目。GitHub 仓库存放代码，不等于已部署网站。GitHub Pages 仅能托管静态前端，不能运行此项目的云同步 API、D1 数据库或 R2 照片存储。

现有云端版本维持私人访问，并使用原有 ChatGPT 登录保护。若需要独立域名、无需 ChatGPT 登录和国内稳定访问，须另外配置可用的后端及托管环境，并实际测试目标网络。仅放到 GitHub 不能保证国内可访问。

Node.js >=22.13。解压后的 README 提供具体结构和运行说明，运行 `npm test` 验证计算和同步逻辑。
